# Chat with Steve

Vite + React + TypeScript + Tailwind + shadcn/ui, with a Supabase backend (database, auth, edge functions), Stripe payments and Resend email. Hosted on Vercel.

## Run locally
```bash
cp .env.example .env     # then paste your Supabase anon/publishable key
npm install
npm run dev              # http://localhost:8080
```

## One-time backend setup (Supabase project `euibgmuegrgnievkgrhj`)
```bash
npm i -g supabase                      # or: brew install supabase/tap/supabase
supabase login
supabase link --project-ref euibgmuegrgnievkgrhj
supabase db push                       # creates tables, policies, email queue, blog-images bucket
supabase functions deploy              # deploys all 7 edge functions
```

### Secrets (Supabase → Edge Functions → Secrets, or `supabase secrets set NAME=value`)
| Name | Where it comes from |
|---|---|
| `STRIPE_SECRET_KEY` | Stripe → Developers → API keys (start with the test key `sk_test_…`) |
| `STRIPE_PRICE_ID_LIVE` / `STRIPE_PRICE_ID_TEST` | Stripe product price IDs. Defaults in `create-checkout` belong to the old Stripe account/products – set these. |
| `RESEND_API_KEY` | Resend → API Keys |
| `SEND_EMAIL_HOOK_SECRET` | Created in the next step (Auth hook) |

`SUPABASE_URL`, `SUPABASE_ANON_KEY` and `SUPABASE_SERVICE_ROLE_KEY` are provided to functions automatically.

### Auth emails via Resend
1. Resend: add and verify the domain `chatwithsteve.co.uk` (add the DNS records it shows).
2. Supabase → Authentication → Hooks → **Send Email** → HTTPS → URL
   `https://euibgmuegrgnievkgrhj.supabase.co/functions/v1/auth-email-hook` → generate secret → save it as `SEND_EMAIL_HOOK_SECRET`.
3. Supabase → Authentication → URL Configuration: Site URL `https://chatwithsteve.co.uk`; add `https://chatwithsteve.co.uk/**` and your Vercel preview URL to Redirect URLs.

### Email dispatcher (runs every minute)
Open `supabase/setup/1-schedule-email-queue.sql`, follow the two steps in the Supabase SQL editor.

### Make yourself admin
Sign up on the live site, then run `supabase/setup/2-make-me-admin.sql` (with your email) in the SQL editor.

## Deploy on Vercel
1. Push this folder to your GitHub repo.
2. Vercel → Add New → Project → import the repo (framework: Vite; build `npm run build`; output `dist`).
3. Environment variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_PROJECT_ID`, `VITE_SUPABASE_PUBLISHABLE_KEY` (see `.env.example`).
4. Settings → Domains: add `chatwithsteve.co.uk` and `www.chatwithsteve.co.uk`, set the DNS records Vercel gives you.
